# netInspect

the network inspector for reverse engineers and curious people

## how to use
 - when you think something will make a web request, hold down **left shift** (or whatever you pick) to start <cg>capturing mode</c> and release to stop
 - after the request has been made, a popup will show up and lets you edit the request
 - finally the game will recieve a reponse and you can edit that too

### note
this only works for vanilla web requests (using CCHttpRequest), any other ways of making requests (such as geode's web::WebRequest) will <cr>not</c> be supported
